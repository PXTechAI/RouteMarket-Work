# Amazon 价格监控 Skill

更新日期：2026-07-24

该场景是 RouteMarket Work 的第一个内置 Workflow Skill，用于验证 Skill
定义、工作流生成、本地工具执行、人机接管和本地产物导出的完整链路。

Skill 负责描述场景、所需能力和配置字段；Workflow 负责确定执行顺序；浏览器与
文件节点负责具体执行。首版随桌面客户端提供，用户无需安装。

Skill 生成的工作流保存 `sourceSkill.id` 和 `sourceSkill.version` 快照，运行记录
因此可以追溯到确定版本。CSV 导出成功后，运行面板提供“打开”和“所在目录”操作。

## 场景目标

用户在 Desktop 中填写一个 Amazon 商品链接和本地保存目录，生成并运行一个
可编辑工作流：

1. 在可见的内置浏览器中打开商品页面。
2. 识别商品名称、价格文本、数值和币种。
3. 整理为一行结构化数据。
4. 生成 Excel 可直接打开的 UTF-8 CSV，并保存到用户选择的目录。

## 第一阶段：单商品闭环

当前实现包含三个可独立配置的本地节点：

- `local.browser.navigate`：打开商品链接。
- `local.browser.product_extract`：使用 Amazon 常见页面选择器回退识别商品名和价格。
- `local.data.csv_export`：经用户确认后把一行商品数据导出到所选目录。

工作流页面通过通用 Skill 注册表发现“Amazon 价格监控”，根据 Skill 声明的字段
生成配置界面和工作流。用户仍可在节点参数编辑器中修改 URL、选择器、文件名和
输出目录。相同文件名不会覆盖已有文件，会自动追加序号。

### 验收标准

- 用户可以从页面生成三节点、两连线的工作流并保存。
- 运行后自动切换到内置浏览器，用户能看到页面加载过程。
- 常见 Amazon 商品页可以识别商品名称和价格。
- 登录或验证码导致识别失败时，暂停当前步骤、发送桌面提醒，并允许用户在内置浏览器处理后从当前步骤继续。
- CSV 包含商品名称、价格文本、价格数值、币种、链接和采集时间。
- 输出目录由系统目录选择器选择；外部写入经过 R2 权限确认。
- 导出不会覆盖同名文件，也不会接受相对输出路径。

## 第二阶段：可靠性与可观察性

- 增加“等待页面元素”节点及可配置超时，适配延迟加载页面。
- 在运行时间线中展示当前浏览器步骤、命中的选择器和结构化预览。
- 识别失败时保存页面截图和有限、脱敏的诊断信息。
- 根据更多站点特征细分登录、一次性验证码和 CAPTCHA 提示；首版统一使用安全的人机接管流程，不额外收集凭据。
- 统一其他本地产物节点的预览、打开和清理策略。

## 第三阶段：多商品与表格累积

- 增加列表输入和 `for-each` 控制节点。
- 支持多个商品 URL 顺序采集、失败重试和单项跳过。
- 将多行结果汇总到同一个 CSV/XLSX，并按商品链接去重。
- 增加低频限速、最大商品数和运行时长限制。
- 支持从现有 CSV 导入商品 URL。

## 第四阶段：价格跟踪

- 支持本地定时触发。
- 保存价格历史并计算涨跌。
- 提供价格阈值和变化比例条件。
- 通过本地通知提示降价或采集失败。
- 用户显式选择后再发布或同步结果到云端。

## 产品与合规边界

- 不绕过登录、验证码、访问控制或站点反自动化机制。
- 不默认执行高频或大规模采集。
- 浏览器会话和本地输出目录只保存在当前设备。
- 工作流运行前明确展示将访问的网站和将写入的目录。
- 后续扩展到其他电商站点时，使用站点适配器，不把 Amazon 选择器硬编码到通用节点。
