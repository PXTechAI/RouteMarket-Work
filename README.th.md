# RouteMarket Work

[简体中文](README.zh-CN.md) · [English](README.md) · [日本語](README.ja.md) · [Español](README.es.md) · [Português](README.pt-BR.md) · **ไทย** · [한국어](README.ko.md)

RouteMarket Work คือเวิร์กสเปซเดสก์ท็อปแบบโอเพนซอร์สและ local-first สำหรับโปรเจกต์และระบบอัตโนมัติที่ใช้ AI โดยรวมไฟล์โปรเจกต์ การสนทนากับ Agent เวิร์กโฟลว์แบบภาพ งานเบราว์เซอร์ เครื่องมือในเครื่อง เซิร์ฟเวอร์ MCP, Skill และขั้นตอนการอนุมัติไว้ในแอป Electron เดียว

> [!IMPORTANT]
> โปรเจกต์นี้ยังอยู่ระหว่างการพัฒนาอย่างต่อเนื่อง ฟีเจอร์บางส่วนเกี่ยวกับบัญชี โมเดล Agent และการทำงานบนคลาวด์ต้องใช้บริการ RouteMarket ที่เข้ากันได้ อินเทอร์เฟซและรูปแบบข้อมูลในเครื่องอาจเปลี่ยนแปลงก่อนรุ่นเสถียร

## ความสามารถหลัก

- โปรเจกต์แบบ local-first ที่เลือกเชื่อมกับโฟลเดอร์ในเครื่องได้
- แชต AI พร้อมเครื่องมือไฟล์ การค้นหา แพตช์ โปรเซส เบราว์เซอร์ MCP และ Skill
- เวิร์กโฟลว์แบบภาพทั้งในเครื่องและบนคลาวด์ พร้อมสถานะการทำงานและฉบับร่างที่ใช้ซ้ำได้
- ระบบอัตโนมัติผ่านโปรไฟล์เบราว์เซอร์แบบแยก หรือเชื่อมต่อ Chromium ในเครื่อง
- การเชื่อมต่อ MCP, Skill ของโปรเจกต์ ทริกเกอร์ในเครื่อง และแอปเนทีฟ
- การตรวจสอบสิทธิ์ การอนุมัติอย่างชัดเจน และการปกปิดข้อมูลสำคัญก่อนส่งข้อมูลวินิจฉัยขึ้นคลาวด์

## เริ่มต้นอย่างรวดเร็ว

ต้องใช้ Node.js 22, Corepack และ pnpm 10.8.1

```bash
corepack enable
corepack pnpm install
corepack pnpm dev:web
```

`dev:web` เป็นหน้าพรีวิวที่ใช้ข้อมูลจำลอง หากต้องการทดสอบ Electron แบบเต็มให้รัน `corepack pnpm dev` โดยค่าเริ่มต้นต้องมี RouteMarket Web ที่เข้ากันได้ที่ `http://localhost:3000` และ API ที่ `http://127.0.0.1:3001`
